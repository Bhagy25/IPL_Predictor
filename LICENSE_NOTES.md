# Attribution, licence and image-rights notes

## Match data: Cricsheet

- All match data comes from [Cricsheet](https://cricsheet.org/), which publishes ball-by-ball data for the
  Indian Premier League.
- This repository includes the Cricsheet IPL JSON files (`data/raw/ipl_json/`) and tables derived from them
  (`data/processed/`, `data/derived/`, `reports/`), so that the analysis can be reproduced.
- Cricsheet makes its data available under the Open Data Commons Attribution License (ODC-By 1.0), which
  allows reuse with attribution. Check [cricsheet.org](https://cricsheet.org/) for the current terms before
  redistributing the data or anything derived from it.
- Credit: **Match data from Cricsheet (https://cricsheet.org/).** Please keep this credit in any copy or
  derivative of the data, tables, charts or models.

## Homepage hero artwork

- The homepage hero (`web/public/assets/hero-desktop.png` and `hero-mobile.png`) is a collage built from
  press photographs of IPL matches and players. The rights to those photographs were **not verified**.
- The artwork is included for academic demonstration of this course project only. It must not be reused,
  redistributed or published commercially; replace it with licensed or original images before any public
  deployment.
- The same applies to `web/public/assets/original_photos/07_ipl_trophy.png`, used as the site icon.

- The Python and TypeScript source code was written for the IT462 Exploratory Data Analysis course project.
